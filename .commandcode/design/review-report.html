P0 · ACCESSIBILITY

Fokus keyboard dihapus tanpa pengganti

Seluruh input memakai focus:outline-none dengan kompensasi bg 5%→10% yang tak terbedakan (index.html:481, 484, 493, 522, 829, 936; feeds.js:424). Screenshot textarea terfokus menunjukkan nol indikator visual.

FIX: Ring focus-visible 2px emerald dengan offset; jangan hapus outline tanpa pengganti yang terverifikasi.
P0 · ACCESSIBILITY

Kontrol ikon tanpa nama; motion tanpa gerbang reduced-motion

Panah slider, dots, dan close modal tanpa aria-label; BGM/burger hanya title tanpa aria-pressed. Slider auto-play tiap 3,5 detik (index.html:1782), bossPulse dan animate-bounce/ping/pulse berjalan infinite — tidak ada prefers-reduced-motion di seluruh file.

FIX: aria-label + aria-pressed; media query reduced-motion untuk mematikan autoplay dan loop infinite.
P0 · ACCESSIBILITY

Modal menangkap mouse, membiarkan keyboard terdampar

Lima modal (index.html:816–948) tanpa focus trap, tanpa inert di background, tanpa Escape (tidak ada keydown handler di seluruh file), tanpa restore fokus — hanya modal admin yang memindahkan fokus masuk (index.html:987).

FIX: role="dialog" + aria-modal, trap fokus, Escape menutup, fokus kembali ke pemicu.
P0 · ACCESSIBILITY + LAYOUT
